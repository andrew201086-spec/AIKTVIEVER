# Просмотр КЛКТ

Просмотр конусно-лучевой компьютерной томографии челюстей в браузере: три проекции, объёмный рендер, панорамная развёртка по зубной дуге и карточки срезов по отдельным зубам.

**Снимок никуда не отправляется.** Файлы читаются и обрабатываются в браузере на компьютере врача; сетевых запросов с данными пациента нет. Разметка врача хранится в IndexedDB того же браузера.

> Программа помогает смотреть и измерять. Она не ставит диагноз: подсказки по разрежениям у верхушек корней — это места, на которые стоит взглянуть, а не заключение.

## Запуск

```bash
npm install
npm run dev
```

Открыть адрес, который напечатает Vite (обычно `http://localhost:5173`). Нет снимка под рукой — кнопка «Открыть тестовую модель челюсти» сгенерирует настоящий DICOM-набор.

Проверки перед коммитом:

```bash
npm run check
```

Это линтер, проверка типов и тесты. Сборка — `npm run build`, публикация на GitHub Pages — автоматическая из CI при push в `main`.

| Панорама | автоподбор зубной дуги, криволинейная реформация с регулируемой толщиной слоя, резкость, экспорт PNG |

```
  components/
    DicomUploader.tsx      чтение файлов, распаковка ZIP, разбор заголовков
    SeriesPicker.tsx       выбор серии и решение о прореживании срезов
    Viewer.tsx             движок Cornerstone, четыре окна, инструменты, клавиатура
    Pane / SliceScroller   номер среза, положение, перемотка
    ArchOverlay.tsx        зубная дуга поверх аксиальной проекции
    PanoramaPanel.tsx      панорамная развёртка, метки зубов, поиск разрежений
    ToothChart.tsx         зубная формула: состояния, заметки, переходы
    ToothCard.tsx          карточка зуба и её экспорт
    MeasurementList.tsx    список измерений
    PlanOverlay.tsx        имплантаты и канал поверх срезов
    PlanPanel.tsx          план: размеры, расстояния, трассировка
    VolumePanel.tsx        обрезка 3D, снимок, экспорт STL
    ReportView.tsx         заключение на печать
    ErrorBoundary.tsx      локализация сбоев
  utils/
    dicomParse.ts          разбор DICOM, группировка серий, проверки геометрии
    customMetadataProvider.ts  метаданные до декодирования пикселей
    cornerstoneInit.ts     инициализация движка и воркеров
    renderCapabilities.ts  что умеет видеокарта; сколько байт стоит воксель
    orientation.ts         где пациент в этой сетке вокселей
    density.ts             что значат серые значения этого снимка
    panorama.ts            криволинейная реформация вдоль дуги
    toothSections.ts       срезы по зубу, нумерация FDI
    toothDetect.ts         поиск зубов по профилю плотности вдоль дуги
    toothChart.ts          модель формулы: что нашлось и что сказал врач
    toothTiles.ts          набор срезов зуба — общий для карточки и отчёта
    measurements.ts        измерения Cornerstone как список
    surgicalPlan.ts        геометрия плана: имплантаты, канал, расстояния
    volumeExport.ts        поверхность по порогу плотности и запись STL
    periapical.ts          поиск разрежений у верхушек
    studyStore.ts          память разметки (IndexedDB)
    recentStudies.ts       недавние папки через File System Access
    annotationMemory.ts    сохранение и восстановление измерений
    demoStudy.ts           генератор тестового DICOM
```

Три вещи, которые стоит понять перед правкой геометрии:

**Ориентация измеряется, а не предполагается.** `orientation.ts` выводит направление осей вокселей в системе пациента из матрицы направления объёма. Всё, что называет сторону — номер зуба, маркер R/L, «верхняя челюсть» — проходит через него. Снимок, собранный в обратном порядке, индексируется точно так же, как правильный, и разница видна только в геометрии.

**Высота считается от макушки.** Все реформации меряют высоту в миллиметрах вниз от верхнего края объёма (`heightToSlice` / `sliceToHeight`), поэтому «выше» всегда означает «ближе к темени», как бы ни были сложены срезы.

**Пороги плотности записаны в единицах Хаунсфилда и пересчитываются.** КЛКТ не калибрована: `density.ts` находит на гистограмме воздух (−1000 HU) и мягкие ткани (0 HU) и строит по двум точкам аффинную шкалу этого снимка. Фиксированный порог «кость = 500» на другом аппарате не работает.

## Ограничения

- Полный объём должен поместиться в память видеокарты (около 1 ГБ). Крупные исследования открываются с прореживанием срезов — программа говорит, какой шаг по Z получился.
- Панорама следует за смещением дуги по высоте, но сама кривая по-прежнему подбирается на одной плоскости; сильный наклон отдельных корней компенсируется ползунками «Спереди» и «Сдвиг».
- Планирование имплантации предварительное: расстояние считается до линии канала, отмеченной врачом, ширина канала в него не входит, хирургический шаблон программа не заменяет.
- STL строится по огрублённой сетке — шаг сообщается после экспорта.
- Зубы определяются по плотности: отсутствующий зуб распознаётся по промежутку, но сомкнутые коронки делятся по средним ширинам, а металлическая коронка «раздувается» артефактом. Номера редактируются в формуле и в карточке.
- Оценка разрежений — эвристика по плотности, не валидированная на размеченных данных. Питательные каналы, костномозговые пространства, нижнечелюстной канал она тоже обводит.
