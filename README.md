# AIKT Viewer

Просмотр отсканированных челюстей и презентация плана лечения пациенту.
Приложение работает целиком в браузере: файлы пациента никуда не отправляются.

Два модуля:

| Модуль | Данные | Назначение |
| --- | --- | --- |
| **Сканы челюстей** | `.ply`, `.stl`, `.obj` | Внутриротовые сканы и сканы моделей, планирование конструкций, презентация |
| **КЛКТ (DICOM)** | `.dcm`, папка, `.zip` | Мультипланарная реконструкция и объёмный рендер конусно-лучевой томографии |

## Возможности модуля сканов

**Просмотр**
- Загрузка верхней и нижней челюсти (челюсть определяется по имени файла: `upper` / `lower`, `верх` / `ниж`).
- Разбор файла в фоновом потоке, ускоренный пикинг по BVH — сканы на миллион полигонов остаются интерактивными.
- Автоматическая ориентация скана в анатомическую систему координат (метод главных компонент + определение окклюзионной стороны по шероховатости поверхности), кнопки поворота и переворота для ручной правки.
- Цветные сканы отображаются с вертексными цветами, монохромные — «гипсовым» материалом; студийный свет, ACES tone mapping.
- Пресеты видов (фронтально, окклюзионно сверху/снизу, справа, слева, только ВЧ / только НЧ) — окклюзионный вид автоматически убирает противоположную челюсть.
- Прозрачность и скрытие челюстей, секущая плоскость по трём осям, измерение расстояний в миллиметрах.

**План лечения**
- Зубная формула FDI: выбор зуба мышью в формуле или прямо на 3D-модели.
- Автоматическое построение зубной дуги по скану и расчёт позиции каждого зуба — конструкция ставится на своё место одним нажатием.
- Конструкции: коронка, винир, вкладка, промежуточная часть моста, имплантат, абатмент. Геометрия строится параметрически по классу зуба (резец, клык, премоляр, моляр) с анатомией жевательной поверхности, поэтому библиотека моделей не нужна.
- Мост: несколько конструкций объединяются в один блок, коннекторы между единицами строятся автоматически.
- Материалы (диоксид циркония, стеклокерамика, металлокерамика, золото, композит, титан) со своими оптическими свойствами и прайсом.
- Ручная доводка положения гизмо (перемещение / поворот / масштаб) и числовые параметры размеров.
- Разбивка плана по этапам, комментарии для пациента, итоговая смета.

**Презентация и вывод**
- Полноэкранный режим презентации: «До лечения» → этапы → итог, автовращение, пресеты видов, крупные кнопки для планшета.
- Печатный отчёт (PDF через печать браузера) со снимками «до / после», этапами и сметой.
- Снимок текущего вида в PNG.
- Сохранение клинического случая в файл `.aikt` (zip: манифест плана + геометрия сканов) и открытие его обратно.

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # продакшн-сборка в dist/
npm run preview  # локальный просмотр сборки
npm run deploy   # публикация dist/ в ветку gh-pages
```

Требуется браузер с WebGL 2 (Chrome, Edge, Safari 16+, Firefox).

## Устройство кода

```
src/
  App.tsx                    выбор модуля
  cbct/CbctModule.tsx        обёртка КЛКТ-модуля (загружается лениво)
  components/, tools/, utils/  существующий КЛКТ-вьювер на Cornerstone3D
  scan/
    types.ts                 доменная модель (конструкции, этапы, случай)
    store.ts                 состояние (zustand)
    data/fdi.ts              нумерация FDI, средние размеры коронок
    data/materials.ts        материалы реставраций
    mesh/meshWorker.ts       разбор PLY/STL/OBJ в Web Worker
    mesh/align.ts            автоориентация скана, построение зубной дуги
    mesh/placement.ts        расчёт положения конструкции на зубе
    mesh/registry.ts         хранилище геометрии и BVH
    geometry/tooth.ts        параметрические коронки, виниры, понтики
    geometry/implant.ts      имплантат и абатмент
    geometry/bridge.ts       коннекторы моста
    io/caseFile.ts           формат случая .aikt
    io/report.ts             печатный отчёт
    components/              интерфейс: сцена, панели, презентация
```

## Ограничения

- Программа предназначена для визуализации и обсуждения плана лечения с пациентом. Она **не является** средством постановки диагноза и не заменяет хирургический шаблон или сертифицированную систему планирования имплантации.
- Коронки и имплантаты строятся параметрически: это анатомически правдоподобные, но не точные модели конкретных систем имплантатов и не CAD-конструкции для фрезеровки.
- Совмещение скана с данными КЛКТ пока не реализовано — модули работают независимо.
